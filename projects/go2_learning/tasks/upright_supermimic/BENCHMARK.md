# v32 起点的短程速度实验

此次实验使用 upright_adaptive_v32_2026-10-27_16-21-06_572791/latest.pt，读取其 run.json 中的奖励、重置、终止、随机化和网络配置。两条训练分别位于 logs/upright_supermimic/benchmarks/；没有修改原 upright 的配置或日志。

## 训练

| 方法 | 并行环境 | 训练 | 计时 | 名义仿真控制步 |
|---|---:|---:|---:|---:|
| SuperMimic 风格 | 64 | 80 cycle | 107.06 s | 204800 |
| PPO | 64 | 250 次更新 | 118.03 s | 384000 |

两者均开启随机化。SuperMimic 将环境分成训练、验证及在线评估组，80 次中策略更新 76 次；PPO 用环境进行训练，采用 checkpoint 的 PPO 配置。两者采集探索方式不同，不能把名义控制步数比值当作样本效率或加速比。

SuperMimic 分段计时在边界执行 CUDA 同步，统计从首个 cycle 到最后一个 cycle，包含模型首次预热、验证和定期保存，不包含 Isaac 启动。PPO 计时覆盖 runner.learn，包含其训练中保存及日志，不包含 Isaac 启动和训练后的最后一次保存。同步与日志开销使两者的绝对时间有测量偏差。

| SuperMimic 阶段 | 总秒数 | 总时间占比 |
|---|---:|---:|
| 仿真采集、策略推理、缓冲和统计，含首次模型校准 | 77.41 | 72.3% |
| 世界模型更新 | 24.62 | 23.0% |
| 验证和门控 | 0.53 | 0.5% |
| Actor 更新 | 2.33 | 2.2% |
| Critic 更新 | 1.67 | 1.6% |
| 日志和检查点 | 0.49 | 0.5% |

采集阶段并非纯物理求解；不能据此断定 PhysX 或任何单个同步点占了全部采集时间。阶段合计的细小差异来自计时边界。

## 真实仿真短测

使用 evaluate.py，种子 123、456、789，每个种子每个策略 16 个环境、900 控制步；开启随机化，但评估时直立初态锥角设为 0。专家与学生的随机扰动分别采样，且实验只训练一次；这里的 3 个种子是评估种子，不是 3 次独立训练。

| 策略 | 三个评估种子的平均奖励/有效仿真秒 | 失败次数 | 平均直立对齐度 |
|---|---:|---:|---:|
| v32 专家 | 2412.90 | 0 | 0.998924 |
| SuperMimic，80 cycle | 2141.15 | 0 | 0.999155 |
| PPO，250 更新 | 1934.54 | 0 | 0.999276 |

每组累计有效仿真时间约 1425.6 s。所有组各有 48 次超时。短测下两条继续训练的策略平均奖励均低于专家，但直立对齐更高；奖励包含多项指标，不能仅凭该数字判断所有方面都退化。随机扰动未逐条配对，这些结果也不能替代多训练种子的严格统计。

此次未测到相同提升目标的达成时间，因此不能计算训练效果加速倍数。名义控制步吞吐亦不等价于学习效率。
