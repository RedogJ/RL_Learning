# 世界模型与 Isaac 的多步预测对照

使用 `train_20261027_213611_299008/latest.pt`（Actor 学习率 1e-5），在真实 Isaac 中采集 32 个环境（16 专家、16 学生）、900 控制步；种子 123、456、789。每组每种子抽取 512 个 32 步连续窗口，不包含失败、超时或等待阶段。使用采集到的真实动作序列，让世界模型从同一真实起点逐步预测；采集没有额外动作探索噪声。

下表是学生轨迹三个种子的均值。此表将真实下一步随机推力上下文提供给模型，是有利于模型的条件预测，而非对未知未来推力的预测。世界模型训练时也是使用记录的下一步推力上下文。奖励率单位为每有效仿真秒，32 步回报为按 gamma=0.99 折扣、仅包含前 32 步非终止奖励的和，没有 Critic bootstrap。

| 指标 | 1 步 | 8 步 | 32 步 |
|---|---:|---:|---:|
| 12 个关节位置预测 RMSE，rad | 0.026 | 0.030 | 0.048 |
| 状态归一化 MSE | 0.026 | 0.039 | 0.117 |
| 该步 Isaac 奖励率 | 2074 | 2181 | 2161 |
| 该步模型预测奖励率 | 421 | 588 | 53 |
| 后腿对称收益的预测偏差 | -1240 | -809 | -882 |
| 截至该步的 Isaac 折扣回报 | 69 | 553 | 1979 |
| 截至该步的模型折扣回报 | 14 | 211 | 363 |

将每步真实状态重新映射为奖励，重建值与 Isaac 的非终止奖励平均绝对误差约 1.1–1.3e-7 / 控制步；因此上述差异不能简单归因于奖励公式本身不一致。v32 奖励快照中 rear_symmetry 的 sigma 为 0.03737 rad、weight 为 2000；关节位置的预测误差与该尺度相当，可能通过指数型奖励被放大，但 RMSE 和左右对称误差并非同一个量，不能直接代入。

在固定相同动作序列时，动作低通的确定性状态被精确更新，因此 action_rate 的模型与真实重建误差为 0。这个结果不能证明闭环想象中 Actor 的动作变化预测正确，因为闭环情况下预测状态会改变后续网络输出。

上述比较不包含失败步骤、推力突变导致终止的窗口、价值 bootstrap 或学习过程中从模型输出重新采样动作。它直接证明这些正常轨迹上的模型奖励预测存在明显偏差，但不单独证明预测偏差导致了策略退化，也没有验证奖励关于动作的梯度方向。未经真实条件验证，不能假设对同一动作的奖励预测误差等同于真实策略梯度误差。

各原始结果位于 `logs/upright_supermimic/paper_trials/train_20261027_213611_299008/model_rollout_diagnostic_{123,456,789}.json`。另有 1e-6 版本的 seed 123 输出。测试脚本为 `diagnose_model_rollout.py`；模型与旧任务配置、权重和日志未更改。
