# 固定数据世界模型学习率对比

## 方法

- 与前次实验使用完全相同的保存轨迹、整条轨迹训练/验证划分、初始 WM、Adam 状态和随机 minibatch 序列。
- WM 学习率在恢复 optimizer 后覆盖；终止头始终保持 2e-4。
- Actor、Critic、归一化、奖励和生产检查点均未修改。
- 对照 2e-4 在前次记录的 0/60/180/600 次更新上精确复现验证指标。
- 主要标准事先确定：16 步位置、姿态、关节角三个验证 RMS 同时不高于原 2e-4 加训 600 次的结果。

## 解释

- 3e-4 在检查的第 360 次更新达到三项主要指标，较原 600 次减少 40%；这是首次测得达标的点，不是稳定达到阈值的保证。
- 3e-4 第 420 次又回摆，第 480/540 次重新达标，第 600 次位置略高于阈值，曲线仍有波动。
- 5e-4 最终精度更好，但较早阶段明显波动，未在检查的较少更新数上同时满足三项阈值。
- 1e-3、2e-3 引发明显的不稳定/精度恶化。
- 终止头的验证误差单独保存在 comparison.json；提高 WM 学习率不等于解决终止头泛化。
- 单片段、单次采样序列，验证集已用于超参数选择，不是独立测试集；不能据此保证在线联合训练同幅加速。

## 文件

- `experiment.py`：读取保存轨迹的独立可复现实验；每次运行要求新的 --output 目录。
- 各子目录 `config.json` / `metrics.jsonl` / `summary.json`：完整记录。
- `comparison.json`：全部验证物理指标和达标结果。
- 正式训练学习率及更新次数保持原设置，本轮只运行独立诊断。
