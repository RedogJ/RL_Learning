# Fixed-start trajectory, reward and termination audit

Frozen checkpoints 3290,3300,3340,3380 from the masked run. One environment, start reference frame zero, observation/action noise disabled. Real actions and reward terms from actual MuJoCo Warp, with one-step head inputs based both on WM-predicted next state and the realized actual next state. Closed-loop H=16 imagined branches start from real saved state/history at steps 10,15,20,24, with observation noise disabled in both real and imagined branches, context friction 0.5. Soft predicted failure = 1-product(1-p). This is a small matched diagnostic; single start and no measurement of stochastic expected failure or actual policy gradient.

Fixed logging: 3340–3360 completion 0%, 3370 31.25%, 3380 100%. In independent 1-env audit 3340 fails at 29 (height error .2624m); 3380 completes at 53 but has .249m height error at step 29, very close to .25m threshold. 3380 ends with body height .1605m vs reference .3369m. 3300 ends .1777m vs .3369m. Episode completion therefore does not imply accurate landing.

Real reward terms are reward rates, integrated by /30. For 3380, joint position integral 17.724 versus total positive components 22.462, approx 78.9%; root position .571, body position 1.007. Large reward fraction is not the same thing as fraction of gradients or causal attribution, and terms are correlated. 3340 reward sum omits -1 terminal penalty from terms dict. The 3300/3380 comparison includes the same reference and deterministic reset but the closed-loop trajectories differ.

Termination diagnostic: 3340 at failing step29 actual height error .2624m; learned termination head queried on real next state outputs ~0.00000023, while on its own one-step WM-predicted state outputs ~0.644. For 3380 step29 real height error .2491m and is not failed, but predicted-state head gives ~0.725. Direct true-state inputs can be out of distribution because training feeds WM predicted states. In closed-loop 16-step imagination seeded from real state at t=.667s, predicted failure probability: 3300 ~0.008 and no real failure in following 16 steps; 3340 ~0.584 and real failure within 9 steps; 3380 ~0.920 and no real failure in the following 16 steps. Values are model outputs under different predicted trajectories, not empirical calibrated probabilities. This demonstrates error in both directions on selected windows, not statistical rates or the unique cause of actor regression.

No training or configuration was changed. Both raw traces and the small read-only replay script are saved here. A real-state analytic end detector combined with a differentiable replacement could be tested as a separate controlled ablation, but changing how termination is predicted departs from the chosen learned BCE paper-alignment and should not be assumed beneficial without a comparison.
