# Critic tail coefficient comparison

Both runs resumed mask model 3380, same recorded seed and settings, 20 cycles, 2048 envs; only tail weight differs (1.0 vs 0.5). Replay was rebuilt; runs are not bitwise matched. Both save 3390 and 3400. Fixed noise-free training evaluation uses 16 envs at identical starting pose: at cycle3390 coefficient 1.0 completed 15/16, 0.5 completed 16/16; at cycle3400 both 16/16. Fixed eval return at 3400 21.687 vs 21.968. These identical initial states do not provide independent task variation.

Read-only independent physics evaluation uses policy snapshots 3380 baseline, 3400 coeff1, 3400 coeff.5. For seeds 121 and 988, 64 envs start at same reference frame zero, realistic per-step observation noise enabled, no action noise, until failure or end. Seed and generated noise sequences are paired in principle, though trajectories may diverge numerically. No randomized physics or terrain. Among 128 noisy-observation trials, completion baseline 84/128, coeff1 113/128, coeff.5 115/128; mean episode reward 18.315, 20.810, 21.229. For coeff1→0.5, 5 paired envs change success→failure, 7 failure→success. The 2/128 net difference is not a reliable broad ranking; there is one training seed per condition.

Restrict to the 82 noise realizations successful for all three: mean body root position error baseline .1762m, coeff1 .1676m, coeff.5 .1663m; mean landing phase (frame>=30) absolute root height error .1818m, .1541m, .1458m respectively; mean root orientation angle errors 18.36°, 19.69°, 18.92°. Survivor restriction is descriptive conditional analysis, not whole-distribution performance; excluded failed trajectories. Current task reward and failure threshold unchanged. These data suggest improvement over baseline but do not show a definitive 0.5 vs 1.0 advantage. Training condition differences besides weight include simulation numerical divergence and on-policy distribution. 20 cycles, two evaluations, two noise seeds, no different reference motions or random physics; visual quality and generalization need more testing.
